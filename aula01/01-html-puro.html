Títulos e parágrafos

HTML é a linguagem que dá estrutura e significado ao conteúdo de uma página. Quem decide a aparência é o CSS.

Um parágrafo é criado com a tag p. O navegador junta todo o texto e quebra as linhas sozinho, mesmo que você pule linhas no código.

Para forçar uma quebra de linha, use a tag br:
esta linha começa em outro lugar
e esta também.

Existem seis níveis de título, de h1 (o mais importante) até h6. Eles organizam o documento; não servem para deixar o texto grande.

Formatação de texto

Importância forte, ênfase, negrito sem importância extra, itálico para termos ou pensamentos e texto sublinhado.

Texto destacado com marca-texto, texto pequeno (letras miúdas), texto removido, texto inserido e texto que já não é correto.

Fórmulas: H2O (subscrito) e E = mc2 (sobrescrito).

A sigla HTML aparece com explicação ao passar o mouse. Um termo sendo definido: marcação é o ato de envolver o conteúdo em tags.

Citação curta: A web é para todos, segundo Tim Berners-Lee. Publicado em 12 de novembro de 2026.

Código e computação: o comando git status mostra o estado do repositório. Pressione Ctrl + S para salvar. A máquina respondeu Arquivo salvo com sucesso. Na fórmula, a variável x vale 10.

Um trecho com span não tem significado próprio: serve só para o CSS "pegar" uma parte do texto.

Artigos dentro de uma div

Tags de estrutura

Dividem a página em regiões: header, nav, main, section, aside e footer.

Tags de texto

Dão significado ao conteúdo: títulos, parágrafos, ênfases, citações e código.

Tags de mídia

Incorporam recursos externos: imagens, áudio, vídeo e outras páginas.
